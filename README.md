# 中鑫之宝 · 专业提词器

单文件网页提词器，零依赖、离线可用，手机电脑均可直接打开 `index.html` 使用。

## 功能

- 字体大小、滚动速度、行距、左右边距可调
- 横屏 / 竖屏一键切换（支持原生屏幕锁定，不支持时自动旋转画面模拟）
- 镜像模式，配合提词器分光镜使用
- 3 秒倒计时开播、进度跳转、剩余时间显示
- 提词时屏幕常亮（Wake Lock），控制栏自动隐藏
- 文稿与设置自动保存在浏览器本地

## 快捷键

| 按键 | 功能 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ↑ / ↓ | 加 / 减速度 |
| + / − | 加 / 减字号 |
| M | 镜像翻转 |
| O | 横屏 / 竖屏切换 |
| F | 全屏 |
| R | 重新开始 |

手机上点按屏幕即可暂停 / 继续。
